# 第十四章 石子

福伯开始跟着苏晚棠出门了。

他不跟着她走进去，不跟她并肩，也不和她说话。通常只是远远地跟着，隔着一整条街或者半条巷子，像一棵会走路的树。苏晚棠第一次发现他的时候吓了一跳——她从药铺出来，福伯正蹲在街对面的墙根下系鞋带，系完了站起来，若无其事地往她这边看了一眼，然后继续低头走路，像在数地上的砖缝。

她走过去，福伯抬头朝她笑了一下。

"姑娘买好了？"

"……买好了。"

"那回吧。"福伯说，"夫人说今儿中午炖了排骨。"

苏晚棠没有说"你不用跟着我"。萧景渊说了"让他跟着"，她知道这话说出去也收不回来。她只是走在前面，福伯跟在后面，中间隔着十几步的距离，不远不近的，像一根看不见的线拴着。

三天下来，她渐渐习惯了。习惯出门的时候知道身后有人，习惯偶尔回头的时候看见福伯在路边看布摊、闻烧饼、和卖菜的老妇人说两句话。他从来不催她，也不问"好了没有"，就那么稳稳地跟着，像侯府里那棵老槐树移到了街上。

第四天，她决定去一趟书铺——上次买纸那家，想找一本《江南风物志》。沈清婉提过，说那家铺子里收了不少旧书，可能有她想要的。

她跟福伯说了去处，福伯点了一下头，照例隔了十几步跟着。

书铺的老板还是那个戴铜边老花镜的老人。苏晚棠进门的时候他正在往架子上摆新收的旧书，听见门响回头看了一眼，点了点头。

"姑娘来了。这次要什么？"

"有没有关于江南风物志之类的旧书？"

老板想了想，放下手里的书，转身在后面的架子上翻了翻，抽出一本薄薄的册子递过来。

"这本你瞧瞧。前两日收的，说是一位南边来的客商带过来的。"

苏晚棠接过来翻了两页，确实是江南的物产志，纸张发黄，边角有些虫蛀，但字迹清晰。她翻到中间的时候，发现书页里夹着一片干枯的花瓣，已经压得很平很薄了，颜色褪成了淡褐色，形状看不出来原是哪种花。

她把花瓣夹回原处。

"多少钱？"

老板报了价，苏晚棠付了钱，把书拿在手里。她转身往门口走，走了两步，忽然停下来。

"老板。"她回头，"前些日子我来买纸的时候，那位买纸的客人——你还记得他吗？"

老板正在柜台后面低头算着什么，闻言抬头想了想。

"记得。个子不高不矮的，穿灰衣裳，话不多，买了三刀纸就走了。怎么了？"

"他后来还来过吗？"

"没再来过。"

苏晚棠点了点头。她把书换了一只手拿着，推门走出去。门外的阳光照在脸上，暖烘烘的。她眯了一下眼，往街对面看了一眼——福伯不在那里。

她的脚步停了一瞬。

然后她看见福伯从街角走过来。他走得不快不慢，和往常一样，手里没有拎东西，空着手。他看见苏晚棠站在铺子门口，不紧不慢地走过来。

"姑娘买好了？"

"……嗯。"

"那走吧。"

苏晚棠看了他一眼。他表情如常，笑眯眯的，像什么也没发生。但她方才出来的时候，街对面确实没有他。

"您方才去哪儿了？"

福伯看了她一眼。那一眼很短，快的像一片叶子从树上落下来，但苏晚棠看见了——他的目光往巷子深处偏了一下，然后又收回来，重新回到笑眯眯的脸上。

"没什么，"福伯说，"风大，眯了眼。"

苏晚棠没有追问。她跟着福伯往侯府的方向走，两个人之间隔着三四步的距离，和以前一样，不远不近的。但她知道福伯在巷子里看见了什么。他不说，她也不问。

她只是把那个"偏了一下"的目光收进了记忆里，和其他碎片放在一起。

回到侯府，苏晚棠穿过正院的时候看见萧景渊站在书房门口，正在和福伯说话。离得远，听不清在说什么。她只看见福伯微微躬着身，声音不高不低地说了几句，萧景渊点了一下头，然后福伯就退下了。

苏晚棠放慢了脚步。

萧景渊转过身来，看见她站在院子那头。他没有走过来，也没有叫她，只是看了看她手里那本旧书。

"买书了？"

"嗯。"

"什么书？"

"江南风物志。"

萧景渊点了一下头，没有接话。他站在书房门口，日光从廊檐斜斜地照下来，把他的影子拉长了一截，铺在青砖地面上。苏晚棠等着他再问一句什么——比如"有没有遇到什么事"——但他没有。他只是看了她一眼，目光在她脸上停了一瞬，很短，像是确认了什么，然后就转身进了书房。

书房的门半掩着，没有关严。

苏晚棠站在院子里，手里握着那本书。她看着那扇半掩的门，站了一息，然后转身往东跨院走。她走了几步，忽然想起福伯站在巷口时那微微的一偏——目光往巷子深处偏了一下，像是看见了什么，又像是没有。

她把那个画面收好，和之前的所有碎片放在一起。

回屋以后，她翻开新买的《江南风物志》。翻到中间的时候，她发现书页里夹着一片干枯的花瓣。淡褐色的，压得很平很薄，看不出来原来是什么花。

她把花瓣看了看，然后夹回原处，合上书。

窗外，老槐树的叶子在风里沙沙地响。

她磨墨铺纸，低头抄书。笔尖落在纸上，沙沙的，一声接一声。
